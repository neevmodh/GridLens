# Deploy GridLens to Zoho Catalyst AppSail

GridLens is deployed through the Catalyst console with a published QuickML endpoint and durable Data Store history. The current identifiers and verification record are in [CLOUD_STATUS.md](CLOUD_STATUS.md). The steps below explain how to rebuild or deploy a separate instance.

## Build the application

Use a Python 3.12 environment for the configured runtime:

```sh
python3 scripts/package.py --install-deps --zip
```

This prepares a clean `build/` with only application code, static assets, local preview model, sample inputs, and vendored production web-server dependencies. It excludes `.env`, run history, training data, test files, and local environments. It also creates `GridLens_AppSail.zip`. Package dependencies from a matching Python runtime rather than copying an entire macOS virtual environment.

For a source-only build inspection, run `python3 scripts/package.py`; this does not install production dependencies and is not yet a runnable cloud package.

## Associate and deploy through the CLI

Install/update and sign in to the official Catalyst CLI following [Catalyst CLI docs](https://docs.catalyst.zoho.com/en/cli/v1/introduction/). In the project directory, initialize/add an AppSail service using your intended Catalyst project. Select the supported Python 3.12 runtime, and point the build path at `build/`.

The CLI generates the project association in `.catalystrc` and an AppSail entry in `catalyst.json`; the existing app-config.json records the current deployment’s non-secret identifiers. Use the intended project’s identifiers and preserve the service association generated by the CLI.

Configure the startup command to:

```sh
python3 -m gunicorn -c gunicorn.conf.py app:application
```

The included `app-config.json` is a template for the service's source configuration. Catalyst CLI versions may regenerate this file during initialization. Retain the startup command, build path, supported Python runtime, and intended public access setting when reconciling the generated configuration. The gunicorn configuration reads `X_ZOHO_CATALYST_LISTEN_PORT` directly; it does not rely on shell variable expansion in the startup command.

Deploy the initialized AppSail service using the official CLI workflow, or upload the prepared ZIP in the Catalyst console and set the same runtime and startup command there.

## Configure credentials

The hosted demo uses AppSail's managed authentication with QUICKML_AUTH_MODE=catalyst, QUICKML_FEATURE_SCHEMA=engineered and QUICKML_REQUEST_MODE=batch. Keep the endpoint key in private server-side environment settings. Direct local inference can instead use OAuth refresh credentials. See [QUICKML_SETUP.md](QUICKML_SETUP.md). Never package credential values.

Set `GRIDLENS_HISTORY_TABLE=92358000000019001` to use the existing durable Catalyst Data Store adapter. Set `QUICKML_REQUEST_MODE=batch` for the verified endpoint and preserve the remaining live settings in CLOUD_STATUS.md / .env.example. `GRIDLENS_DATA_DIR` is only the fallback local SQLite location; an unconfigured local server uses it for development.

The dashboard is intended to be publicly accessible for judging, with no Catalyst login required to open it. Live QuickML credentials remain server-side. Run history uses a separate HttpOnly, SameSite browser cookie and is not listed globally. Before running an unrestricted public service long term, add your chosen authentication/quota policy to limit use of the paid inference endpoint.

## Verify the generated public URL

1. Open `/` and confirm the hosted dashboard restores a saved QuickML run or generates one from the labeled historical sample.
2. Open Model & research and inspect the published model information.
3. Upload a valid 24-row CSV and select QuickML. Confirm the successful run is labeled QuickML.
4. Inspect rows at 18:00 and 22:00, a demand above 160 kW, and an overload at or above 200 kW.
5. Export the forecast and compare the timestamp and row count with the input.
6. Refresh and inspect run history. Verify no secrets appear in static assets or API responses.
7. Run the original evaluator against the same published endpoint with the local flag disabled.

Do not submit the localhost URL. Submit the public URL returned by Catalyst.
