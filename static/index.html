Connect your published model

Add the endpoint and OAuth credentials on the server, then choose QuickML when creating a forecast.

  1. Train a regression pipeline

    Use the official training CSV, or the prepared time and weather features. Select target_demand_kw as the target.

  2. Publish a model endpoint

    Copy the endpoint URL, key, and sample request from your Catalyst console.

  3. Configure server credentials

    Follow the project setup guide, matching your endpoint’s request format and Zoho data center.

  4. Run a live forecast

    A successful QuickML run verifies the connection. Live failures are shown explicitly.
